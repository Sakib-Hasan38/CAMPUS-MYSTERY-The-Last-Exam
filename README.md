## 📖 About the Game

**CAMPUS MYSTERY: The Last Exam** is a 2D top-down adventure and puzzle-solving game developed using Python and Pygame.

The story begins when an important final examination question paper mysteriously disappears from the university. The player takes the role of a student detective who must investigate the campus, collect hidden clues, solve educational puzzles, and discover the truth behind the missing examination paper.

During the investigation, the player explores different university locations, including the campus, library, computer laboratory, and a secret underground laboratory.

However, the journey is not easy. Security robots patrol the university buildings, locked doors block important areas, and challenging puzzles must be solved to progress through the mystery.

The ultimate mission is to recover the missing examination paper and successfully complete the investigation.

## 🎯 Game Objectives

- Explore different locations around the university campus.
- Investigate the mystery of the missing examination paper.
- Collect keys, books, and hidden clues.
- Avoid security robots and dangerous obstacles.
- Solve programming and general knowledge puzzles.
- Unlock restricted rooms and secret areas.
- Complete all missions and recover the missing examination paper.

## 🕹️ Game Controls

|---|---|
| **W** | Move Up |
| **S** | Move Down |
| **A** | Move Left |
| **D** | Move Right |
| **E** | Interact / Collect Items |
| **SPACE** | Confirm Puzzle Answer |
| **P** | Pause / Resume |
| **R** | Restart Game |
| **ESC** | Quit Game |

## 💻 Installation and Setup

Follow these steps to run the game on your computer.

### 1. Install Python

Download and install Python from:

https://www.python.org/downloads/


### 2. Open the Project Folder

```bash
cd campus-mystery
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the Game

After development, run the main Python file:

```bash
python main.py
```

## 📅 7-Week Development Roadmap

The game will be developed step by step over seven weeks.

### Week 1 — Foundation
- Set up Python and Pygame.
- Create the game window.
- Set screen resolution and frame rate.
- Add the university campus background.
- Implement the main game loop.
- Add basic exit functionality.

**Expected Result:** A working game window with an initial campus environment.

### Week 2 — Player
- Create the student character.
- Display the player on the campus.
- Implement WASD movement.
- Add four-directional movement.
- Control player speed.
- Prevent movement outside screen boundaries.
- Implement basic character animation.
- Add wall and obstacle collision.

**Expected Result:** A controllable student character that cannot pass through walls and obstacles.

### Week 3 — Enemies
- Create security robot enemies.
- Display enemies in the game.
- Implement automatic enemy movement.
- Add enemy patrol movement.
- Implement player-enemy collision.
- Add player health and lives.
- Introduce obstacles.
- Test collision detection.

**Expected Result:** Moving security robots, collision detection, and a working health system.

### Week 4 — Basic Game
- Add collectible books, keys, and clues.
- Implement item collection using the E key.
- Add interactive objects.
- Display the player's score.
- Display health and lives.
- Implement the game-over condition.
- Create a game-over screen showing the final score.
- Add restart and quit functionality.

**Expected Result:** A basic playable game that satisfies the mandatory game requirements of the lab assignment.

### Week 5 — Missions
- Implement locked doors.
- Add key-based door unlocking.
- Add computer and bookshelf interactions.
- Create educational multiple-choice puzzles.
- Add programming and general knowledge questions.
- Display correct and incorrect answer feedback.
- Add puzzle rewards.
- Create library and computer laboratory environments.
- Implement level progression.

**Expected Result:** Multiple environments with collectible items, locked areas, puzzles, and mission progression.

### Week 6 — Polish
- Create the start menu.
- Add an instruction screen.
- Implement pause and resume.
- Increase enemy speed and difficulty.
- Add a countdown timer.

**Expected Result:** A more complete game with advanced gameplay features and improved user experience.

### Week 7 — Submission
- Test all implemented features.
- Fix programming errors and bugs.
- Test player movement and collision detection.
- Test enemy movement and difficulty.
- Test collectibles, keys, and puzzles.
- Verify score, health, timer, and high score.
- Test game-over, victory, pause, and restart.
